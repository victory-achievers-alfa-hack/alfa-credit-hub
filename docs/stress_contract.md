# Стресс-сценарии выручки v1

`backend.src.scoring.stress_financing(company, product, *, purpose, amount, term_months, evaluated_at)` возвращает чувствительность выбранного варианта к снижению выручки. Входной контракт — как у assess_financing. Версия stress-v1.1.0. Компактный результат stress_summary подключён к API рекомендаций, форме заявки и карточкам клиента/банка.

Сценарии: снижение выручки на 0, 10, 20, 30 процентов. Новая выручка округляется HALF_UP до копейки. Расходы, старые платежи, кредитные условия и нефинансовые данные фиксированы. Для каждого сценария повторно вычисляются score, покрытие, предварительный исход и причины. Альтернатива внутри evaluation не заменяет исходный кредит: все сценарии сравнивают одну и ту же запрошенную сумму.

## Запас по покрытию

Минимальная выручка R_required = расходы + исходный_порог * (существующие платежи + новый платёж).

revenueHeadroom = текущая выручка - R_required (может быть отрицательным).

maxRevenueDeclinePercent = 100 * revenueHeadroom / текущая выручка, если выручка положительна и запас неотрицательный. Если исходный вариант уже нарушает покрытие или выручка нулевая, возвращается null, а не вводящие в заблуждение 0 процентов. На точной границе возвращается 0, покрытие проходит. requiredMonthlyRevenue сохраняет точность расчётного порога (может иметь доли копейки); для отображения минимальной достаточной денежной суммы округлять вверх до копейки. Сценарный coveragePasses вычисляется до округления отображаемого отношения.

Порог характеризует только покрытие, не окончательную доступность и не вероятность дефолта. Просрочка, документы, скоринг и ограничения продукта могут блокировать заявку даже при положительном запасе. Все предположения возвращаются в assumptions; данные времени и версии — calculatedAt/stressVersion.

## Пример

«Зёрна», 800 000 рублей, 24% на 24 месяца: платёж 42 296.88 рубля, минимальная выручка по покрытию 990 371.10 рубля. Запас до порога — около 17.47% текущей выручки. При снижении на 10% покрытие проходит, на 20% и 30% — нет. Это условный сценарий при неизменных расходах, не прогноз бизнеса.

Тесты: `python -m unittest discover -s tests -v`. Проверяются сохранение исходных условий, числовой пример, точная граница, исходный дефицит, нулевая выручка, отдельная блокировка по просрочке, монотонность, отсутствие мутаций и воспроизводимость.

Основание: дополнительная функция по нашему плану DS, согласующаяся с рекомендацией PDF задания использовать механики с объяснимой ценностью. Это не обязательное требование организаторов и не банковский стресс-тест. Комиссии, изменение расходов, сезонность и вероятности сценариев не моделируются.

## Подключение 25 октября 2026

Исходный порог — 1.25 для стандартного профиля либо 1.50 для диапазона 50–69. Этот порог фиксируется для вычисления запаса и coveragePasses во всех сценариях. При этом policyPasses пересчитывается для нового профиля: ухудшение score может изменить требования или заблокировать предложение даже при прохождении исходного покрытия. В интерфейсе эти два результата показаны отдельно.

В рекомендациях stress относится к фактически показанным сумме и сроку, в том числе уменьшенной альтернативе. В заявке результат сохраняется в input_data снимка на момент подачи. В карточках он подписан как анализ исходного запроса: последующий оффер банка может отличаться. Старые заявки без stress не получают выдуманный результат задним числом. Повторная оценка решения банка записывает стресс для предлагаемых условий в аудит решения.

Раздел интерфейса раскрывается по желанию пользователя. Сценарии не меняют состояние заявки, сохранённый балл или порядок ранжирования. Нет требования проходить все стресс-сценарии для одобрения. Это диагностическая функция с фиксированными расходами, а не прогноз изменения бизнеса.

Дополнительно проверены порог 1.50, соответствие компактного ответа полному расчёту, анализ выбранной альтернативы, сохранение результата в заявке и аудит решения. Набор после интеграции: 71 тест и 64 вложенные проверки; frontend build и lint проходят.

В браузере на отдельной тестовой базе проверены раскрытие сценариев и соответствие показанных платежей и покрытия расчёту «Зёрна» на 800 000 рублей, 24 месяца.
