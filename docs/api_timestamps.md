# Время в API

25 октября 2026. Поля datetime в ApiSchema приводятся к UTC. Если SQLite вернул datetime без часового пояса, он трактуется как UTC: именно в UTC сервис записывает события и снимки. Значения с явным смещением переводятся в UTC с сохранением момента времени. Даты регистрации без времени не меняются.

Это исправляет различие между ответом сразу после создания заявки и повторным чтением: раньше calculatedAt и createdAt могли потерять суффикс Z. Проверки — backend/tests/test_timestamp_serialization.py и сквозной сценарий изменения профиля после подачи заявки.
